# AWS architecture icons

rkeytect renders AWS-style diagrams and maps recognized services to stable `iconKey` identifiers.

The repository does **not** copy AWS artwork into source code until the correct official asset source and permitted use are verified. This avoids shipping unverified third-party icon packs while preserving the rendering contract.

When official assets are added, each asset should retain its provenance and the project should link users to the current AWS architecture icon resource.
