# Evidence Fusion

This package is deliberately conservative.

It keeps article text, source diagrams, code, and external references as separate evidence kinds. A relationship is not authoritative merely because two components occur in the same article or diagram.

## Promotion rules

- `confirmed`: explicit source evidence supports the relationship.
- `inferred`: interpretation is plausible but not explicitly established.
- `recommended`: generated by a Solution Architect review, never source architecture.
- `conflict`: competing evidence remains unresolved.

The UI must preserve these states and the original source reference. AI-generated output must always be labeled as AI-generated and verified before production use.
